# Автоматическое размещение

По умолчанию `height=None` включает оценку высоты, `top=None` — последовательное размещение. Формулы, таблицы, текст и графики добавляются через обычные методы листа или `add`. Расстояние между выделенными областями — 12 pt; первый автоматический регион начинается с 12 pt. Размеры указаны в пунктах.

Оценка намеренно простая и консервативная:

- Учитывается размер шрифта листа. Строкам и символам выделяется высота с запасом.
- У дроби складываются высоты числителя и знаменателя. Для степеней, индексов, корней и пределов добавляется запас. Вложенные выражения измеряются рекурсивно.
- Высота матрицы складывается из максимальных высот ячеек каждой строки. Программа измеряется по строкам.
- Текст оценивается по числу символов, ширине поля и переносам строк. Измерение шрифтов и точная типографика не используются.
- Результату известного матричного размера выделяется место по числу строк; таблице выделяется минимум 20 строк, место под заголовок и рамку. Известное большее число строк увеличивает высоту.
- Для графика выбирается высота по ширине (не менее стандартных 220 pt), а последующий регион размещается с запасом под подписи осей. Явная `height` задаёт высоту графика, резерв под подписи сохраняется.

`Worksheet.layout()` и сериализация пересчитывают автоматические размеры и позиции. Добавление копирует объект региона, поэтому повторное использование одного объекта не связывает его позиции. После изменения выражения вызовите `layout()`, если нужно прочитать актуальные координаты до записи файла. Явные `top` и `height` сохраняются; их достаточность обеспечивает вызывающий код.

## Размер результата

Генератор не выполняет расчёты Mathcad. Он отслеживает размеры матричных литералов, известных определений, индексов, диапазонов и распространённых операций (`transpose`, `augment`, `stack`, `lsolve`, `rkfixed`, `Rkadapt`). Для простых пользовательских функций учитывается форма возвращаемого выражения. Программы с циклами могут менять размер массивов и требуют явного `ResultShape` для вывода результата.

Вызов функции на диапазоне (`g(k) =`, где `k` задан `Range`) получает табличный запас даже при скалярном результате самой функции. При неизвестной длине диапазона или явном `MatrixStyle.TABLE` используется минимум `ResultFormat.table_min_rows` строк (по умолчанию 20); настройка не ограничивает количество результатов Mathcad. Ось региона располагается в середине зарезервированного места. Пример: `examples/range_tables.py`.

Если форма результата неизвестна и табличный вывод не указан, запись документа завершается `LayoutError` с просьбой задать форму. Например:

```python
from xmcd import MatrixStyle, ResultFormat, ResultShape, Symbol, Worksheet

sheet = Worksheet()
# Функция external должна быть определена выше в реальном документе.
sheet.evaluate(
    Symbol('external')(1),
    result_shape=ResultShape(rows=30, columns=4),
    result_format=ResultFormat(matrix_style=MatrixStyle.TABLE),
)
```

Для заведомо скалярной непрозрачной функции укажите `ResultShape.scalar()`. Альтернатива — явная `height`. Форма, переданная вызывающим кодом, должна соответствовать реальному результату. Вложенные матрицы в ячейках результата и необычное оформление могут требовать явной высоты. Для символьного результата заранее неизвестно дерево выражения: `Symbolic` требует явную `height`.

Оценка предотвращает наложения при генерации и проверена по реальным границам сохранённых Mathcad документов. Она не гарантирует сохранение расстояний после произвольного редактирования в самом Mathcad, смены шрифтов или изменения числа строк результата. Автоматическое горизонтальное разбиение очень широких формул и перенос регионов целиком на следующую страницу не выполняются.

Готовый пример: `examples/layout.py`. Связанные проверки: `tests/test_layout.py`; нативные образцы и версия Mathcad — в [совместимости](compatibility.md).

Для прочитанного XMCD размеры сохраняются до явного `reflow()`: [чтение и повторная расстановка](reading.md).
