# Чтение и редактирование XMCD

`Worksheet.read(path)` или `Worksheet.read(xml_bytes)` возвращает `LoadedWorksheet`: лист с обычными регионами и выражениями, а также сохранёнными исходными настройками и вложениями. Поддерживается классический XMCD worksheet30 версии 3.0.3. Сжатые XMCDZ и Mathcad Prime MCDX не поддерживаются.

```python
from dataclasses import replace
from xmcd import Define, MathRegion, Worksheet

sheet = Worksheet.read("input.xmcd")
region = next(r for r in sheet.regions if r.tag == "input-a")
if isinstance(region, MathRegion) and isinstance(region.expression, Define):
    region.expression = replace(region.expression, rhs=4)
sheet.text("Параметр изменён из Python")
sheet.reflow()
sheet.write("edited.xmcd")
```

Выражения неизменяемы: используйте `dataclasses.replace` или присвойте региону новое выражение. Доступны определения, вызовы функций, арифметика, матрицы, диапазоны, интегралы, производные, суммы, программы и решающие блоки. Греческие символы и буквенные индексы читаются в `Symbol` и `LiteralSubscript`. Регионы можно добавлять обычными методами листа, удалять и переставлять через `sheet.regions`. Простые абзацы читаются в `TextRegion`; области — в `Area` с относительными координатами детей.

## Сохранность документа

Без изменений `to_bytes()` возвращает исходные байты. При редактировании сохраняются настройки, идентификаторы, двоичные вложения и непредставленные в модели XML-свойства. Поддерживаемые изменения применяются к исходному дереву. Изменение формулы, расчётных настроек, положения, состава или порядка регионов удаляет сохранённые результаты и изображения вычислений: Mathcad должен пересчитать документ.

Неизвестное выражение становится `OpaqueExpression`. Неподдерживаемый регион, сложный форматированный текст и импортированный двоичный график становятся `OpaqueRegion`. Их содержимое сохраняется; регион можно переместить или удалить. Для изменения содержимого замените его поддерживаемым объектом. Импорт графика пока не восстанавливает `XYPlot` и `Trace`; новые графики можно добавлять через обычный API.

`write()` сохраняет собственную проверку библиотеки. Неизвестные регионы дают предупреждение `opaque-region`; `warnings_as_errors=True` запрещает такую запись. Ошибки уже существующего документа также могут блокировать `write()`. `to_bytes()` остаётся низкоуровневой сериализацией без семантической проверки. Сохранность неподдерживаемых элементов не означает проверку их вычислений или безопасности внешних компонентов.

## Повторное размещение

После чтения размеры и позиции явные: обычная запись сохраняет исходную вёрстку. `reflow()` заново оценивает высоты и выстраивает регионы сверху вниз в порядке списка. У неизвестных результатов и непрозрачных регионов сохраняется исходная высота. Метод рассчитан на последовательный документ; исходная раскладка в несколько колонок заменяется последовательной. Горизонтальные координаты сохраняются.

Для табличного результата резервируется минимум `ResultFormat.table_min_rows` строк, по умолчанию 20. Это параметр Python для размещения, он не записывается в настройки Mathcad. Чтобы изменить его после чтения, замените локальный `region.result_format` либо настройку листа, если у региона нет локальной. [Расчёт размеров](layout.md).

Пример с загрузкой сохранённого Mathcad-документа: `examples/edit_document.py`. Нативные регрессии проверяют изменение `a := 2` на `a := 4` и пересчёт `a³ + 1 = 65`, сохранность нетронутых формул и побайтовое сохранение документов без правок.
