# Совместимость и приёмка

Целевой формат: классический XMCD, пространства имён `worksheet30` / `math30`, версия документа `3.0.3`. Mathcad Prime MCDX является другим форматом.

## Подтверждено

- Генерация XML на Linux: Python + lxml, без Windows, COM и установленного Mathcad.
- Лист, настройки страницы, стили текста, координаты и отдельные координаты выравнивания регионов.
- Математические и текстовые регионы, вложенные области, независимые идентификаторы при повторном использовании объекта.
- Числа, строки, символы, буквенные индексы, арифметика, вызовы и определения функций, матрицы, индексирование, диапазоны, производные, интегралы, суммы, условные программы.
- XSD-проверка с локальными схемами установленного Mathcad. Схемы PTC не включаются в пакет; передайте путь в `validate(path, schema=...)`.

## Реальный пересчёт

В VM установлен executable версии **14.1.5.594**, несмотря на имя каталога `Mathcad 15`. Пример `examples/core.py` открыт через Windows UI MCP, пересчитан и сохранён через «Сохранить как». Сохранённый файл: `tests/fixtures/core-mathcad14.xmcd`.

| Проверка | Сохранённый результат |
|---|---:|
| Арифметика `2³+1` | 9 |
| Несимметричная матрица, элемент `[0,1]` | 2 |
| Определитель | −2 |
| Функция `g(2)` | 12 |
| Производная `g` в точке 2 | 14.000000000000009 |
| Интеграл `x²` от 0 до 1 | 0.33333333333333337 |
| Сумма от 1 до 5 | 15 |
| Программа `if / otherwise` | 3 |
| Индексируемый вектор с диапазоном | 9 |

Файл содержит все девять числовых результатов и не содержит сохранённых ошибок вычисления. `test_native_evidence.py` проверяет эти данные. Это регрессионный образец; запуск pytest сам по себе не запускает Mathcad и не подтверждает новые возможности.

`examples/solvers.py` также открыт, пересчитан и сохранён в VM. В `tests/fixtures/solvers-mathcad14.xmcd` подтверждены решение системы `(3, 2)` и параметризованный блок `positive_root(9) = 3`, без сохранённых ошибок. API: `Given()` и `Solver(SolverKind.FIND)(x, y)`; `Minerr` и оптимизация проверены отдельным примером ниже; `Odesolve` проверен в `advanced.py`, см. ниже.

Редактируемые XY-графики, три трассы функций и параметрическая окружность проверены через UI и сохранены в `tests/fixtures/plots-mathcad14.xmcd`. [Формат, пример и ограничения графиков](plot-format.md).

## Границы поддержки

- Проверена версия Mathcad 14.1.5.594; Prime MCDX не поддерживается.
- Нет 3D-графиков, OLE/ActiveX-компонентов, импорта произвольного существующего XMCD, полной типографики Mathcad.
- Настройки графиков покрывают используемые примерами линии, точки, пределы и сетку; логарифмические оси, отдельные подписи и специальные маркеры осей не реализованы. Опорные прямые можно задать дополнительными трассами.
- Встроенные функции доступны через `BuiltinFunction` или явный `Symbol`; живые проверки подтверждают перечисленные сценарии, а не все функции и комбинации аргументов Mathcad. Символьное вычисление проверено на `factor`.
- Книга служит перечнем конструкций. Полная численная копия каждого её расчёта не входит в набор примеров; связаны расчёты компрессора и кулачка.

Открытие файла, XSD-валидация и отсутствие сохранённых ошибок без сохранённых результатов недостаточны для приёмки вычислений.

## Численные функции и программы

`examples/numerics.py` и `examples/programs.py` пересчитаны в той же VM; сохранённые документы находятся в `tests/fixtures/`. Подтверждены:

- `linterp`, `lspline`, `pspline`, `cspline`, `interp`, `root` и `angle`.
- `lsolve`, `augment`, `stack`, число строк/столбцов, транспонирование, извлечение столбца, поэлементная векторизация и расширение массива присваиванием последнему элементу.
- `rkfixed` и `Rkadapt` для `y′ = y`, матричный результат из 21 строки и двух столбцов. Конечные значения: 2.7182816926563351 и 2.71828182845532.
- Вывод матрицы таблицей и перевод `1000 mm = 1 m`.
- Локальные присваивания, `for`, `while`, `break`, `continue`, `return`, `tryCatch`, логические условия и `otherwise`.
- Символьная команда `factor`: `x² − 1 → (x − 1)(x + 1)`.

Математическая ось высокого региона располагается в середине заданной `height`. Для таблицы из примера выделено 300 pt; сохранённые границы таблицы не пересекают соседние формулы. Для автоматического размещения используется консервативная оценка размеров; см. [размещение](layout.md).

`examples/optimization.py`: подтверждены ограниченная минимизация `(x−3)²` при `x≥0` с решением 3, максимизация `10−(x−2)²` с решением 2 и `Minerr` для несовместных уравнений `x=1`, `x=3` с решением 2. Сохранённый образец: `tests/fixtures/optimization-mathcad14.xmcd`.

Полярный годограф с функциональной трассой и вектором состояния пересчитан и сохранён в `tests/fixtures/hodograph-mathcad14.xmcd`; [снимок и API](plot-format.md#полярные-годографы).

## Вложенные выражения и связанный расчёт

`examples/precedence.py` проверяет 16 случаев группировки операций. Сериализатор автоматически добавляет `ml:parens` там, где визуальный приоритет Mathcad может изменить дерево: сумма в произведении, правая часть вычитания, основание степени и другие вложенные операции. Явные скобки доступны через `Parens(value)` или `expression.parens()`.

`examples/compressor.py` связывает геометрию компрессора, производные первого и второго порядка, инерцию, табличные сплайны давления, интеграл работы, четыре редактируемых графика и таблицу 13×5. Сохранённый образец `tests/fixtures/compressor-mathcad14.xmcd` не содержит ошибок или выделений аудитора. Положение, обе производные, момент инерции 0.081071408907 и момент сил проверены независимыми аналитическими формулами в тестах. Интеграл за цикл — −837.632807747; это результат данного примера, а не утверждение о точном воспроизведении всех чисел книги.

Тест также сравнивает сгенерированные и сохранённые деревья выражений этих двух примеров: Mathcad сохраняет порядок операций. Отсутствия `error` недостаточно: аудитор может исправить дерево и затем успешно вычислить изменённую формулу.

В UI Mathcad параметр `n1` изменён с 10 на 20, выполнен пересчёт и сохранён `tests/fixtures/compressor-edited-mathcad14.xmcd`. Длины звеньев, положение, скорость и работа за цикл уменьшились вдвое. Документ закрыт и повторно открыт без сообщений аудитора; это проверка редактирования без повторной генерации Python.

`examples/cam.py` проверен в Mathcad и сохранён в `tests/fixtures/cam-mathcad14.xmcd`. Ход после нормировки — 0.0150000019925 м, остаточное перемещение в конце цикла — −6.61×10⁻⁷ м. Given–Find даёт `s0 = 0.0252931343`, `e = 0.00398639982`; углы давления в контрольных точках равны ±30°. Все шесть графиков сохранены; деревья формул сохранены без перестановки операций. Числа соответствуют построенному вычислительному примеру, без обещания совпадения всех округлений книги.

## Дополнительные операторы и области

`examples/advanced.py` и `tests/fixtures/advanced-mathcad14.xmcd` подтверждают открытые и свёрнутые области, вычисление скрытых определений, глобальное определение выше своего положения, разрыв страницы, извлечение строки, векторное произведение, сумму элементов, произведение ряда, факториал, корень пятой степени, логарифм по основанию 2, сопряжение комплексного числа, модуль и строковую функцию. `Odesolve` для y′ = y, y(0) = 1 даёт y(1) = 2.7182855132 при стандартном допуске 0.001.

Документ также закрыт, повторно открыт, пересчитан и сохранён: скрытое определение `hidden = 13` сохранено.

Координаты дочерних регионов API относительны области; в открытой области сериализатор переводит их в абсолютные координаты XMCD, а в свёрнутой сохраняет относительными. Прямой `matrow` из XSD не читается этой версией Mathcad, поэтому библиотека записывает эквивалент через транспонирование и `matcol`.

## Пакет и автоматические проверки

Wheel `xmcd-0.2.0-py3-none-any.whl` установлен в отдельное окружение Python 3.11.15 вне рабочего дерева. Все 14 примеров сгенерированы установленным пакетом и прошли XSD-проверку. Runtime-зависимость — только lxml. Исходный архив содержит библиотеку, примеры, документацию и регрессионные тесты; исследовательские материалы, страницы книги и прежняя библиотека исключены.

Автоматический набор: 84 теста на Python 3.14, проверка Ruff. Тесты проверяют структуру, сериализацию и сохранённые нативные результаты; полноценный пересчёт выполнялся отдельно через Windows UI MCP.

## Автоматическое размещение и типизированное оформление

`examples/layout.py` создаёт документ без ручных высот: переносимый текст, вложенные дроби, матрица 8×3 с дробными элементами, вывод матрицы и таблицы, программа, интеграл, два последовательных графика. В Mathcad пересчитаны и сохранены варианты с шрифтом 10 и 14 pt; `tests/fixtures/layout-{10,14}-mathcad14.xmcd` проверяются по фактическим границам регионов. Все соседние регионы разделены положительным зазором, ошибок вычислений и выделений аудитора нет. Проверены Unicode α, φ, ω, θ, буквенные и числовые индексы; контрольная сумма равна 15.

Это проверка консервативной оценки на указанных сценариях, а не воспроизведение шрифтового движка Mathcad. Произвольные результаты неизвестного размера требуют `ResultShape` или явной высоты; изменение параметров в самом Mathcad может изменить размеры результатов.
