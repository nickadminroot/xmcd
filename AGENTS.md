# xmcd

Python-библиотека для создания документов Mathcad XML (XMCD) без установленного Mathcad и Windows COM.

Перед работой прочитайте [README.md](README.md).

- Python-зависимости управляются `uv`; runtime библиотеки не использует Mathcad, COM или Windows.
- `mathcad_xmcd_generator/` — исключённый из Git справочный материал, не зависимость новой библиотеки.
- `research/` и `output/` — локальные источники исследования и проверочные артефакты.
- XML-проверки и реальный пересчёт Mathcad являются разными уровнями проверки; документируйте их отдельно.
- Windows UI управляет основной агент; согласовывайте с ним любые действия на общем рабочем столе.

- `Worksheet.write()` выполняет семантическую проверку; низкоуровневые `to_xml()` / `to_bytes()` её не выполняют. Контракт и границы анализа — в [docs/validation.md](docs/validation.md).
